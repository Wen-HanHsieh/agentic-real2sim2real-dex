← 2×2×2 Cube Solving

What an agent receives after a submission

A complete example under feedback protocol v2 for 2×2×2 Cube Solving. Every response below was produced by the same target-environment API calls an agent makes, on infrastructure-test submission s12 (a policy package from an earlier experiment, replayed to test the pipeline; not a research result). Commands are written as in REMOTE_API.md. Long arrays are shortened for display (marked “… N more”) and hashes are abbreviated; nothing else is changed. Timestamps in responses are UTC (received 2026-10-22 20:14 EDT, Pittsburgh).

ReturnedCommand
1acknowledgement with preflight timingsubmit
2state: queued → running → donestatus
3Standard feedback, stored for every rollout and pulled with fetch: three camera videos, robot log, calibration, official evaluation, object tracks, masksfetch sNN
4optional query, not charged: RGB / depth frames at any instant and viewframes
5optional query, not charged: selected masks as PNG with metadatamasks
6optional: all submissions with official results, regression gate, best policy, noteshistory, note
7optional: the exact package of any earlier submissionpackage sNN

Only step 1 comes back with the submission; everything else the agent requests. The policy itself never sees images during the trial; everything is available after the rollout. The operator's private ground-truth comparison is never returned.
