# Human Demonstration: Ball Toss, Catch, and Spin

The video demonstrates the skill to reproduce with the Wuji Hand 2: toss a ball, catch it, spin it in the hand, and hold it.

## Files

- **Video:** `IMG_9943_h264.mp4` (7.27 s, 30 fps, H.264); `IMG_9943.mov` is the original recording.
- **Sampled frames:** `frames/` (12 frames).

The ball in the video differs from the target baseball (`object/SPECS.md`). The video illustrates the skill, not the exact target object or initial conditions.

The demonstration is for offline analysis and policy development. During target execution the deployed policy receives only the observations in `../CONTRACT.md`.
