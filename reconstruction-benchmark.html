Limitations

  • Equal budgets: same model and settings, 2 GPUs, 22 CPU threads and 160 GiB each, the same inputs; the comparison points are 30 min, 1 h, 1.5 h and 2 h after start.
  • Reference masks are an independent 2D reference, not 3D ground truth; mask agreement verifies position and outline, not full 3D orientation.
  • Agentic Reconstruction builds its object models from the given object dimensions; parts of its motion are modelled (tennis free flight constrained to gravity, pen roll and ball spin held fixed, cube layer turns not reconstructed).
  • Do as I Do's object meshes come from SAM 3D Objects at the pipeline's own metric scale (the plugs come out at about two thirds of their real size).
  • Both agents stopped 3 h 32 min after start on a shared usage limit; results after 2 h are not part of this comparison.

1. What each approach actually used for the 3D hands

Agentic Reconstruction

  • hand estimator: HaWoR network (ThunderVVV/HaWoR @ 66c7d41, hawor.ckpt) run per frame by the agent's own driver (solution/hands/hawor_run.py): WiLoR detector (detector.pt) -> HaWoR model inference in the camera frame with the agent's own focal length. HaWoR's DROID-SLAM world stage and its motion infiller were NOT used.
  • hand masks: SAM 3 (staged weights) hand masks, used as silhouette targets and for the validity rule.
  • refinement: MANO fitting package (handlib/fit.py) initialised from HaWoR, against the agent's own MuJoCo object scene. Tennis/plug/cube: the supplied fit.py unchanged, re-run with non-default configs (contact and penetration weights, fixed scale, smoothness; plug and cube also depth_order). Pen: a modified copy (mano_fit_dense) adding triangle centroids and edge midpoints as penetration/contact probes; cube: a copy adding per-side freeze. All recorded in each task's hands/config.json, MODIFICATION.md and provenance.json.
  • validity rule: package README section 5: fitted-silhouette IoU >= 0.5 against the SAM 3 hand mask (per frame).
  • camera focal: assumed for tennis (1500 px) and pen (1000 px); fitted to manually read corners with the known object size for plug (~2043 px) and cube (~886 px); principal point at the image centre; static camera except plug (rotation from background SIFT, translation fixed).
  • object hand coupling: strong: the hand fit includes contact and penetration terms against the agent's own object scene, and object poses were jointly refined with the hands on some tasks (plug); objects use the given dimensions.

Do as I Do

  • hand estimator: HaWoR inside the published do-as-i-do pipeline (malik-group/HaWoR fork @ 2c3fa0c, its demo.py) with the static-camera flag: detector + HaWoR motion estimation + the HaWoR infiller, MoGe focal. A numerical guard was added for fully-masked attention rows (NaN fix, recorded in MODIFICATIONS.md). The DROID-SLAM dynamic-camera branch was built later for plug/pen trials but the T+2h deliverables use a static camera.
  • hand masks: SAM 3 masks used only for visibility QA of infilled hands (accepted only with mask support, IoU >= 0.25, recall >= 0.5).
  • refinement: none on the hands (no MANO fitting); the pipeline's Stage-4 translation/scale optimisation anchors object translation and scale to the HaWoR hands. A single SPECS-derived global scale correction per task is applied to objects and hands together (tennis 0.993), uncorrected outputs kept.
  • validity rule: detector-observed frames with finite, in-front vertices; infilled frames only with SAM 3 mask support.
  • camera focal: MoGe per-frame estimate at the reference frame (tennis ~1767 px, pen ~1214 px, plug ~1566 px, cube ~1268 px); static camera.
  • object hand coupling: weak: objects come from SAM 3D Objects + Fast-SAM3D pose prediction; hands only anchor the metric translation/scale (Stage 4); no contact or penetration terms.

8. Limitations (what cannot be verified without 3D ground truth)

  • Absolute depth and metric scale: both depend on each method's focal length (assumed or estimated) and scale anchor; the reference masks only constrain the projection. The two methods' camera frames are not registered to each other.
  • Contact and penetration are geometric distances between delivered surfaces; whether the real hand touched the real object is not observable here. The 5 mm contact band is a heuristic.
  • Known-geometry distances use the published object dimensions placed at the delivered pose through a rigid alignment of the known shape to the method's own mesh (ICP, no scaling); for Do as I Do's plugs, whose meshes are about 0.6–0.7× the known size, this alignment has 7–9 mm residual and the distances mix pose and size errors.
  • Own-mesh distances are signed only for watertight meshes (all Agentic meshes; no Do as I Do mesh), otherwise unsigned.
  • Agentic Reconstruction's hand fit optimises contact and non-penetration against its own scene, so its low penetration partly reflects that objective rather than an independent measurement.
  • Do as I Do at T+2h has object tracks for tennis (226 frames) and pen (149) but only a reference-frame pose for plug and cube, so its 3D hand–object interaction is not available for those tasks.
