Definitions and accuracy

  • measured Tokens and tool calls: summed from each agent's Codex session logs (token_count events, exact counters reported by Codex). If an agent is restarted, the new session is added to the old one.
  • measured Submissions, budget, validate calls: SuperDex cell records and access log; exact timestamps. Validate calls before each agent's start (operator setup checks) are excluded.
  • measured GPU-hours: a 30 s sampler on the instance (nvidia-smi). "GPU-hours" = device utilization attributed to the agent's processes × time; "alloc" = time the agent holds a process on a GPU × number of GPUs. Short jobs (< 30 s) can be missed. Sampling started 2026-10-21T20:10:42Z; GPU use before that is not measured.
  • measured CPU core-hours: CPU-time growth of the agent's live processes between samples; processes that exit between two samples are partly under-counted.
  • derived Elapsed: now − first Codex session event. Active: time covered by session events with gaps ≤ 5 min (the agent working or waiting on short commands); long waits on background jobs count as inactive.
  • estimate Cost: AWS Spot price for g6e.12xlarge in us-east-2c ($5.3032/h, 2026-10-21T13:00:00+00:00; on-demand $10.49/h). Per-agent GPU cost = allocated GPU-hours × Spot/4. The instance is billed as a whole, so idle GPUs and CPU are not attributed to agents.
  • unavailable Codex model cost: the agents authenticate with a ChatGPT plan, which does not bill per token. Per-agent GPU energy: power is only measured per device.

Operator monitoring only. It reads process tables, nvidia-smi and log files; it never writes to agent workspaces or changes their research.
